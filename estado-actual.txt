### Motor de imágenes: fal.ai (Flux Pro)

Proveedor activo: `IMAGE_PROVIDER=fal`

Flujo en `image_providers.py`:
1. `fal_client.run("fal-ai/flux-pro/v1.1", { prompt, image_size: "landscape_16_9", steps: 28 })`
2. Descarga PNG desde URL temporal de fal
3. Overlay copy/CTA con Pillow → `static/images/fal_<uuid>.png`
4. Retorna URL local para el publisher Go

ComfyUI fue evaluado y descartado: GPU local (GTX 1650 Ti / 4 GB VRAM) insuficiente para modelos modernos.
fal.ai resuelve esto sin infraestructura local.

### Cómo levantar el stack completo

Documentación detallada con comandos exactos (Windows): **`infra/arranque-stack.md`**

**Prerequisitos (una vez):**
```bash
pip install -r requirements.txt   # incluye fal-client
python -m alembic upgrade head
cd frontend && npm install && cd ..
```

**Servicios (terminales separadas — desde la raíz `Marketing DEPA IA`, venv activado):**

```bash
# T1 — Infra (PowerShell o Git Bash)
docker compose -f infra/docker-compose.yml up -d

# T2 — Ollama (servicio en background; verificar)
curl http://localhost:11434/api/tags

# T3 — API
python -m uvicorn gateway.app.main:app --reload --host 127.0.0.1 --port 8000

# T4 — Celery
python -m celery -A workers.celery_app.celery_app worker -l info

# T5 — Frontend
cd frontend && npm run dev

# T6 — Go publisher (solo al aprobar/publicar en IG)
cd microservices/social-publisher-go && go run ./cmd/server

# T7 — ngrok (solo al publicar en Meta/Instagram)
cd tests/ngrok-v3-stable-windows-amd64 && ./ngrok.exe http 8000
# Actualiza PUBLIC_IMAGE_BASE_URL con la URL https y reinicia Uvicorn
```

Dashboard: http://localhost:5173 · API docs: http://127.0.0.1:8000/docs

### Prometheus (métricas) — desactivado en dev

`prometheus-fastapi-instrumentator` está comentado en `gateway/app/main.py` por incompatibilidad con FastAPI >= 0.115.

**Reactivar obligatoriamente antes de producción:** descomentar las dos líneas marcadas con `[PROMETHEUS]` en `main.py`. Expone `GET /metrics` para conectar con Grafana.
