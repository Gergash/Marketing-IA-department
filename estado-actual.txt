### Cambio reciente importante: **fal.ai** (no ComfyUI en código)

Tu `.env` ya tiene:

```env
IMAGE_PROVIDER=fal
FAL_API_KEY=...
FAL_MODEL=fal-ai/flux-pro/v1.1
```

El flujo en `image_providers.py`:
1. `fal_client.run("fal-ai/flux-pro/v1.1", ...)`
2. Descarga PNG → overlay copy/CTA → `static/images/fal_*.png`

**ComfyUI ya no está implementado** en `image_providers.py` (solo queda mencionado en un comentario de `settings.py`). Para fal **no necesitas** ComfyUI ni GPU local.

## Probar fal.ai (generación)

1. Abre http://localhost:5173  
2. Brief: tema, `instagram`, objetivo, etc.  
3. **Enviar async** (requiere Celery)  
4. Espera ~15–60 s (Flux Pro en la nube)  
5. En **Resultado**: imagen en `/static/images/fal_....png`  
6. Estado: `pending_approval`

**Logs esperados:** `image.fal_generated`, `image.fal_saved`

**Si ves placeholder mock:** falta `pip install fal-client` o `FAL_API_KEY` vacía/incorrecta.

### Prueba rápida por API

```bash
curl -s http://127.0.0.1:8000/api/health

curl -s -X POST http://127.0.0.1:8000/api/briefs \
  -H "Content-Type: application/json" \
  -d '{"tema":"Prueba fal Flux","publico_objetivo":"emprendedores","red_social":"instagram","objetivo":"branding"}'

curl -s -X POST http://127.0.0.1:8000/api/runs/async \
  -H "Content-Type: application/json" \
  -d '{"brief_id":1,"publish":false,"requires_approval":true}'

curl -s http://127.0.0.1:8000/api/runs
```
