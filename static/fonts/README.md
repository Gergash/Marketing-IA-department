# Tipografías empaquetadas (OFL / SIL)

Usadas por el overlay Pillow. **No** las dibuja Fal/Venice/SD.

## Reglas de uso

- **Títulos**: pueden variar (script, display condensado, sans Black, serif Black).
- **Subtítulos / cuerpo bajo el título**: solo pesos **Bold / ExtraBold / Black** (nunca Regular, Light ni Thin).
- La familia **varía por imagen** según seed (`arquetipo:red:tema`).
